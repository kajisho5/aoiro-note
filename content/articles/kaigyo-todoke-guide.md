## 開業届とは

開業届の正式名称は「個人事業の開業・廃業等届出書」です。個人事業を始めたことを税務署に届け出る書類で、事業を開始した日から1か月以内に提出することとされています。

期限を過ぎても罰則はありません。ただし、青色申告をしたい場合は後述の承認申請書に厳しい期限があるため、開業届は開業直後にまとめて出してしまうのが安全です。

## 開業届の書き方

主な記載項目は次のとおりです。

| 項目 | 書き方 |
|---|---|
| 納税地 | 自宅住所（自宅兼事務所なら自宅）。届出先はこの住所を管轄する税務署 |
| 氏名・生年月日 | 本人のもの。押印は不要 |
| 個人番号 | マイナンバーを記入 |
| 屋号 | 事業用の名称。空欄でも可（後からでも使えるが、控えに屋号を残したい場合は記入） |
| 開業日 | 実際に事業を始めた日 |
| 職業 | 「映像制作」「Webデザイン」など具体的に |
| 事業の概要 | 仕事内容を簡潔に。複数ある場合は併記 |
| 所得の種類 | 通常は「事業所得」にチェック |
| 青色申告の承認申請 | 同時に提出する場合は「有」にチェック |

用紙は税務署の窓口か国税庁サイトで入手できます。記載例も国税庁サイトに掲載されています。

## 一緒に出すべき届出

開業届と同時に、または近いタイミングで必要になる届出は次のとおりです。

### 青色申告承認申請書

青色申告で確定申告するための申請書です。提出期限は、開業した年は**開業日から2か月以内**（通常はその年の3月15日まで）。この期限を過ぎると、その年は白色申告になってしまいます。最大65万円の特別控除など青色申告のメリットは大きいため、開業届と必ずセットで提出してください。詳しくは[青色申告の始め方](/articles/aoiro-shinkoku-guide/)で解説しています。

### その他の届出（該当する人だけ）

- **青色事業専従者給与に関する届出書**：家族に給与を払う場合
- **給与支払事務所等の開設届出書**：従業員や専従者に給与を払う場合
- **源泉所得税の納期の特例の承認に関する申請書**：源泉所得税の納付を半年に1回にまとめたい場合

## 提出方法は3つ

1. **税務署の窓口**：その場で控えに受付印をもらえる。初めてで不安な場合はこの方法が確実
2. **郵送**：控え用のコピーと返信用封筒を同封すると、受付印を押して返送してもらえる
3. **e-Tax**：自宅から送信できる。控えはメッセージボックスに届く受信通知で代用する

どの方法でも、提出した証拠（控え）が残る形にしておくことが大切です。

## 開業届の控えが必要になる場面

- 屋号名義の銀行口座（事業用口座）を開設するとき
- 小規模企業共済や補助金に申し込むとき
- 保育園の入園審査など、就労証明の代わりとして求められるとき

「提出したけれど控えがない」という事態を避けるため、提出方法は控えが確実に残る形を選びましょう。

## 届出のあとは帳簿付けを始める

開業届を出したら、日々の取引を帳簿に付ける習慣をすぐ始めます。青色申告の65万円控除には複式簿記が必要ですが、クラウド会計ソフトを使えば銀行・カード連携で仕訳の大部分が自動化できます。ソフトの選び方は[会計ソフト3社比較](/articles/freee-mf-yayoi-hikaku/)を参考にしてください。
