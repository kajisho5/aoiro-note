## 経費の基本的な考え方

経費とは、売上を得るために必要だった支出のことです。「事業との関連性」と「説明できること」が判断基準になります。税務調査で問われたときに、なぜその支出が事業に必要だったのかを説明できれば、経費として認められやすいと言えます。

逆に、生活費は経費にできません。線引きがグレーな支出ほど、メモや証跡を残しておくことが重要です。

## 経費にできるもの（例）

| 勘定科目 | 支出の例 |
|---|---|
| 租税公課 | 事業税、印紙代、固定資産税（事業用部分） |
| 水道光熱費 | 事務所の電気・ガス・水道代（按分対象） |
| 旅費交通費 | 電車・バス・タクシー代、出張の宿泊費 |
| 通信費 | 携帯電話、インターネット回線（按分対象） |
| 広告宣伝費 | Web広告、チラシ、名刺作成 |
| 接待交際費 | 取引先との飲食代（事業関係のもの） |
| 消耗品費 | 文房具、10万円未満の備品、ソフトウェア |
| 外注工賃 | 外部の業者・フリーランスへの発注費 |
| 地代家賃 | 事務所家賃、自宅兼事務所の按分分 |
| 支払手数料 | 振込手数料、決済サービスの手数料 |
| 新聞図書費 | 業務関連の書籍・サブスクリプション |
| 研修費 | 業務スキル向上のためのセミナー受講料 |

## 経費にできないもの（例）

- 所得税・住民税（租税公課にも入りません）
- 国民健康保険料・国民年金保険料（経費ではなく「社会保険料控除」で申告します）
- プライベートな飲食・買い物
- スーツ代など、プライベートと区別しにくい被服費（業務専用の作業着などは認められる場合があります）
- 罰金・延滞税などのペナルティ

## 家事按分の考え方

自宅で仕事をする場合、家賃や電気代、通信費は「事業で使った分」だけ経費にできます。これを家事按分（かじあんぶん）と言います。

按分の割合は、面積比・使用時間・使用日数など、合理的な基準で決めます。

計算例：家賃月8万円、自宅のうち仕事スペースが全体の25%の場合
- 8万円 × 25% ＝ 月2万円を地代家賃として経費に計上

大切なのは、割合の根拠を説明できることです。「部屋の間取り図で仕事スペースが4分の1だから25%」のように、基準をメモに残しておきましょう。クラウド会計ソフトには按分を自動で仕訳する機能があり、毎月の手間を減らせます。

## 領収書・レシートの保管ルール

- 青色申告の場合、帳簿と領収書などの書類は原則**7年間**の保管が必要です
- 領収書が発行されない支出（電車運賃など）は、日付・金額・行き先・目的をメモした出金伝票で代用できます
- クレジットカードの明細は領収書の代わりにはならない場面があるため、利用明細やレシートも一緒に残すのが安全です

## 電子帳簿保存法のポイント

2024年1月からは、メールやWebサイトから受け取った領収書・請求書などの「電子取引データ」は、紙に印刷しての保存ではなく、**電子データのまま保存することが義務**になりました。検索できる形で保存する要件もあります。

実務上は、電子で受け取った書類を会計ソフトに取り込んで保存するのが一番確実です。各社の電子帳簿保存法への対応は[会計ソフト3社比較](/articles/freee-mf-yayoi-hikaku/)でも比較しています。
